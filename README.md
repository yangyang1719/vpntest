# VPN 测试

这是面向临时 Ubuntu 22.04 云服务器的 AmneziaWG 安装脚本原型。

**当前状态：仅做过 shell 语法检查，尚未在 ECS 或客户端上验证。** 脚本不会创建或删除阿里云实例、磁盘、安全组或公网 IP。IPv6 没有通过隧道，不能保证隐私保护。请勿将此原型用于需要可靠安全保障的场景。

脚本位于 `scripts/install-amneziawg.sh`，会安装官方 AmneziaWG 软件包、修改 IPv4 转发及防火墙规则、启动服务并在服务器的 `/root/awg-client.conf` 生成包含私钥的客户端配置。该配置必须保密，绝不要提交到 Git 或公开分享。ECS 安全组需要允许所选 UDP 端口入站。实例删除后需另行检查磁盘、公网 IP 等资源是否仍在计费。

该脚本会更改服务器系统配置，并要求 root 权限。使用前请先审阅脚本，在可销毁的测试服务器上验证客户端连接、DNS、重启及异常清理行为。
